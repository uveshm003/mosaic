# 0001. Project name: Mosaic

Date: 2026-10-30
Status: Accepted

## Context

The spec left the project name open, with Facets as the working name and Mosaic, Kaleido and Atelier as alternatives.

## Decision

The project is named Mosaic: distinct profiles that together form one picture. The repo is `mosaic` and packages use the `@mosaic/*` scope.

## Consequences

Mosaic is a common name, so search results will clash with other projects. The brand name is a separate decision and stays open.
